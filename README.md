# Свет по движению

**Свет по движению** — пользовательская интеграция для Home Assistant, которая управляет светом и другими устройствами по одному или нескольким датчикам движения.

Интеграция позволяет отдельно настроить **включение** и **выключение**, учитывать **освещённость**, ограничивать работу **по времени** и показывать **диагностические сенсоры** с понятными статусами.

## Возможности

- Включение по одному или нескольким датчикам движения
- Выключение после отсутствия движения
- Отдельные списки устройств:
  - для включения
  - для выключения
- Задержка включения: **0–300 секунд**
- Задержка выключения: **0–10 минут**
- Ограничение по времени:
  - для включения
  - для выключения
- Учёт освещённости:
  - выбор датчика освещённости
  - минимальная освещённость
  - максимальная освещённость
- Режим **Только свет**
- Русский интерфейс настройки
- Диагностические сенсоры уровня “почему сейчас не сработало”

## Логика работы

### Включение
1. Любой из выбранных датчиков движения переходит в состояние `on`
2. Проверяются:
   - включён ли блок включения
   - разрешено ли включение по времени
   - проходит ли условие по освещённости
3. Если включена задержка — интеграция ждёт заданное количество секунд
4. Если условия всё ещё выполняются — выбранные устройства включаются

### Выключение
1. Все выбранные датчики движения переходят в состояние `off`
2. Запускается задержка выключения
3. Если за это время движение вернулось — таймер отменяется
4. Если движения нет до конца таймера — выбранные устройства выключаются

## Установка

### Вручную
1. Скопируйте папку `custom_components/off_light` в:
   ```text
   /config/custom_components/off_light
   ```
2. Перезапустите Home Assistant
3. Перейдите в **Настройки → Устройства и службы**
4. Нажмите **Добавить интеграцию**
5. Найдите **Свет по движению**

### Через HACS
1. Откройте HACS
2. Добавьте этот репозиторий как **Пользовательский репозиторий**
3. Тип репозитория: **Integration**
4. Установите интеграцию **Свет по движению**
5. Перезапустите Home Assistant
