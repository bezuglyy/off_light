# Off_light v3.0.0

## Что нового
- добавлено включение устройств по движению;
- добавлено выключение устройств по отсутствию движения;
- поддержка одного или нескольких датчиков движения;
- отдельные списки устройств для включения и выключения;
- независимые switch-сущности для блокировки включения и выключения;
- задержка включения 0–300 секунд;
- задержка выключения 0–10 минут;
- режим только для `light.*`;
- условие по освещённости с датчиком lux и порогом;
- диагностические сенсоры для отладки;
- новые иконка и логотип;
- подготовка репозитория для GitHub/HACS.

## Установка
1. Скопировать `custom_components/off_light` в `/config/custom_components/off_light`.
2. Перезапустить Home Assistant.
3. Добавить интеграцию **Off_light** через UI.

## HACS
Добавьте репозиторий как **Custom repository** с типом **Integration**.

## Важно
Для старых конфигураций включение не навязывается автоматически: существующие записи безопасно мигрируются без внезапного автозапуска света.
