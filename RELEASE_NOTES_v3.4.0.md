# Release v3.4.0

## Что нового
- Финальная GitHub-сборка интеграции **Свет по движению**
- Полное русское описание для GitHub и HACS
- Новые иконка и логотип
- Стабилизирован `options_flow`
- Сохранены:
  - включение по движению
  - выключение по отсутствию движения
  - временные ограничения
  - диапазон освещённости
  - диагностические сущности

## Основные функции
- Один или несколько датчиков движения
- Раздельные устройства для включения и выключения
- Задержка включения и выключения
- Ограничение по времени
- Учёт освещённости
- Русский UI

## Установка
1. Скопировать `custom_components/off_light`
2. Перезапустить Home Assistant
3. Добавить интеграцию **Свет по движению**
